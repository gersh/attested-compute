# Exact reference-certificate example

Run `create_example.py` from the repository root to reproduce the canonical
`batch.json`, then follow Example 1 in [`../README.md`](../README.md). The
expression is `x * (1 + y)` and deliberately includes both point and non-point
interval inputs.

The generated result and certificate belong under `build/`; the checked-in
batch is the only retained data input.
